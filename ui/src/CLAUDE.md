# ui/src/ — React UI (map, not a manual)

Mirrors the backend. Vite + React + Zustand + ReactFlow (`@xyflow/react`).

- `store/runStore.ts` — Zustand store; the pure `applyEventToGraph` + `totalLlmCost` re-implement the backend's reduction (the store's `applyEvent` just calls them).
- `hooks/useRunStream.ts` — one `EventSource` per selected run; `RunList` polls `/runs` ~3s.
- `components/RunList.tsx` — **app-grouped sidebar**: groups runs into apps via `lib/building.ts`'s `appKey`/`groupApps` (key = `app_id ?? label`); expand an app → run-history rows (select → inspect/replay).
- `components/AgentGraph.tsx` — dagre layout + ReactFlow; node color = kind (`KIND_BG`), border = status.
- `types/events.ts` — TS mirror of `vapviz/events.py`.
- `lib/theater.ts`, `lib/sprites.ts` + `lib/officeArt.ts` + `lib/officeScene.ts` + `OfficeStage.tsx` (the sprite office — full-size in the Theater tab, `compact` in the Building's rooms; desks assigned by sorted agent name so seats stay stable; art rules in the `pixel-art-set` skill, provenance in `lib/ASSETS.md`) — **UI-only presentation** of the already-derived graph.
- `lib/building.ts` + `components/BuildingView.tsx` — the Office Building monitor (`view:"floor"`): pure `buildBuilding(runs, prev, dismissed)` placement (stay put → failures stay red + surface to `Building.lounge` → seat new → descend cascade; 6 rooms/floor), polled `/runs`+`/graph`, dismiss persistence in `localStorage["vapviz.dismissed"]` (pruned on load). **Visual building (4b):** CSS shell (roof/slabs/lobby directory board), 2×3 rooms around a Walk Way, Door/Stairs column; `lib/loungeArt.ts` + `LoungeStage.tsx` (break-room diorama, per-agent idle activities); `lib/walkOverlay.ts` (sprite layer above the rooms — descent walks Walk Way→Stairs *vanish*→Door below, failures walk to the lounge; FLIP is the fallback, reduced-motion snaps). **Floor life (4c):** the same overlay also runs a persistent layer (`reconcileFloorLife`, called each poll) — one honest walker per *running* room mills on its floor's Walk Way (out a `.vt-room-door` on the room's corridor edge), plus a decorative ambient stroller only on floors where nothing runs; no floor life under reduced-motion.

## Sharp edge — DUAL LOGIC (must stay in sync)
`applyEventToGraph` / `totalLlmCost` (runStore.ts), `types/events.ts`, and the cost reduce here MUST track their Python counterparts in `vapviz/` (`_apply_event_to_graph`, `events.py`, `_total_cost`) — guarded by the cross-impl parity test (`runStore.parity.test.ts` ↔ `tests/test_reducer_parity.py`, shared fixtures in `tests/fixtures/reducer_parity/`). See `vapviz/CLAUDE.md`. **Exempt:** `lib/theater.ts` / `lib/sprites.ts` / `lib/officeArt.ts` / `lib/officeScene.ts` / `lib/building.ts` / `OfficeStage` / Theater + Building views only re-present derived data, so they are *not* part of the dual-logic rule. (`app_id` is likewise outside it: set at run creation from `agent_start` data, never touched by the reducers.)
